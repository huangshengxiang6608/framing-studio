# E2.189 平面量距工具

點工具列「量距」，選擇斜向／實距、水平 X 或垂直 Y。依次點第一點、第二點，再點一下放置尺寸線。連續量度可直接選下一組點。尺寸以 m 顯示，最多三位小數，讀取模型座標，不改動任何荷載或幾何計算。

游標靠近柱中心、梁／牆端點或中點、板角點及軸線交點時會顯示捕捉框。按 Alt 暫停捕捉。中鍵或空格＋左鍵仍可平移，滾輪縮放。Esc 先取消未完成尺寸，再按退出。Delete／Backspace／Ctrl+Z 只撤回量距，不刪構件；輸入欄正常編輯。工具列可撤回或清除本層量距。

量距只在本次開啟期間保留，按樓層及 Framing 分開；切層取消未完成尺寸，重新開啟專案清空。3D 及報表頁停用工具。所有量距置於平面前景。

驗證：獨立 Chrome 合成專案測試端點捕捉、8 m 實距、X/Y 分量、8.944 m 斜距、尺寸線放置、Esc/Delete/undo、平移縮放、3D 停用、清除及專案資料未變。人工檢視畫布截圖。所有其餘計算模組、Section A／B 報表、模板、VBA 和原 EXE 逐檔核對不變。
