# E2.198 CB 出圖支承連動

「18 幾何與出圖」移動 CB 後，原先接在該 CB 的 MB／SB／TB 梁端會跟隨該接點的位移，另一端保留自身出圖位置，因而伸長／縮短。CB 端點因支承柱移動而改變時，沿 CB 原接點位置分配位移。梁和 CB 同時移動不重複累加。

連動識別使用原模型接點。原端點已有直接柱／牆支承，或同時接到多個 CB 而關係不明時，不額外套用 CB 位移；附近但不相接的梁不會被吸附。本次不新增 CB 之間的連鎖支承推斷。

出圖 CB 的實線輪廓不再被相接的 MB／SB／TB 裁斷；這些梁的邊線在進入 CB 梁面時裁去。柱牆仍蓋在梁上方。背景線及板方向線沿用梁面遮線規則。畫布與打印／SVG 一致，選取、量距及圖紙邊界檢查使用連動後位置。

保存重開、恢復 Functional Framing 及撤銷保留。Functional Framing、實際支承及荷載計算未修改；Section A／B 原生圖形與格式、Excel 模板及 VBA 保留。

驗證：兩個軸向、兩種端點次序，CB 移動後相接梁伸縮、CB 完整輪廓及其他梁線裁切，共同移動無重複位移，保存重開／恢復，鄰近及歧義接點排除、柱經 CB 傳遞出圖位移。獨立 Chrome 測試 CB 移動、延長段選取、恢復及撤銷，並檢視截圖。既有柱連動、多選、完整框選、Shift 取消、Column above 回歸通過。模型及荷載列不變，五個樓層原生報表符號／預設 SVG 一致；報表／模板／VBA／EXE 逐檔不變。
