# E2.176 八項修改差異

| 問題 | E2.175 | E2.176 |
|---|---|---|
| 1 板寬 | 主畫面列 X×Y、計算 B | 主畫面集中 L 與 h；幾何及自重計算保留，B 覆寫收進進階設定 |
| 2 跨度框重複 | 另有跨度來源與整個計算跨度框 | L/h 合併在頂部，直接輸入跨度；套用或恢復自動，沒有來源選擇下拉框 |
| 3 Support 模式 | 先切換自動／手動才能選支承 | 每格直接預填自動支承，已改格單獨保存；其餘保持自動 |
| 4 反力單位 | 單位只寫在表外說明 | 表頭直接標示 DL／LL · kN/m |
| 5 Section A 說明 | 長說明佔據主畫面 | 摺疊「支承類別的用途」，保留 A 限值与 B 分析模型的區別 |
| 6 L/h 結果 | 小字一行 | 22px 加粗、狀態色，附 L 與 h；通過／不通過仍以文字顯示 |
| 7 鋼筋率 | 只顯示直徑及間距 | 增加所需／實配主筋 As、As/bd%，以及分布筋 As、As/bh% |
| 8 Framing 預設 | 藏在 Summary Check 底部 | 公用輸入最上方「00 參數」集中材料、預設尺寸及各 Framing 高度 |

## 操作

- 板的 L 預填現有中心距。修改後按「套用跨度」；厚度及跨向沿用即時套用方式。「恢復自動」直接清除跨度／面積覆寫並更新所選板。
- 新的手動跨度預設仍按實際淨面積計自重，不會因修改 L 而增加整塊板的自重；既有手動 B 及 L×B 自重選擇保留在進階設定。
- Support 格的「自動：構件」代表跟隨模型；選定構件代表該段已指定。可逐格選回自動，或使用整板恢復自動。
- 「00 參數」的尺寸即時套用且可撤銷，共同材料使用「保存共同參數」。各 Framing 的 Structural Depth 獨立保存；清空即重設為目前樓層推算高度，並非建立持續跟隨樓層的連結。局部高度仍在 02 樓層設定。
- 配筋率使用既有計算結果與實際選筋：主筋所需／實配 As 除以 1000×d；分布筋 As 除以 1000×h。面積單位 mm²/m，深度 mm，鋼筋率為百分比。沒有改動選筋規則。
