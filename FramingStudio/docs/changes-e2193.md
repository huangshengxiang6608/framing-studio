# E2.193 出圖梁柱多選

「幾何與出圖」右側表格只列已選構件。無選取時只顯示操作提示；取消勾選會把該列移除。先在圖上選取，再按米數移動。

選取類型加入 COL 柱，並提供「全部梁／柱」。類型限制作用於圖上單擊及框選；已選的其他類型仍保留在清單。梁與柱可一起移動、保存及恢復 Functional Framing。原有梁位移資料兼容。

框選使用完整包圍規則：構件的整個平面範圍須在選框內，擦邊、交叉或只包住部分不選入；左右兩個拖動方向相同。單擊及框選累加，Esc 清除。柱按完整截面判斷，不會只包住上下層分割顯示片段就選取整支柱。上層參考柱不能在本層選取移動。

柱位置調整只作用於本頁平面、標註、量距和打印／SVG；不改實際柱位、柱受荷面積、支承或荷載。當層柱符號分片一起移動，上層參考圖形保持原位。恢復清除目前 Framing 的全部梁柱出圖位移，可撤銷。

驗證：獨立 Chrome 確認已選清單、取消勾選、柱與梁共同移動、部分框選不選入、完整框選、反向拖動、類型限制、清除／恢復。原有保存／重新開啟、撤銷、四方向移動及 Delete 防護測試通過。計算案例確認原模型、荷載列不變；五個樓層的原生報表圖形及預設 SVG 與 E2.192 完全一致。計算程式、Section A／B 報表檔、模板、VBA、EXE 逐檔保留。
