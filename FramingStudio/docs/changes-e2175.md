本次以 E2.174 為基礎。所有長度以 m、截面尺寸以 mm 計。

## 圖中 SL-04 的計算

板的實際淨尺寸為 2.500 × 1.575，主欄此前四捨五入顯示 2.50 × 1.58。

- X 方向兩側梁闊均為 1.500：2.500 + 1.500/2 + 1.500/2 = **4.000 m**。
- Y 方向支承梁闊為 1.500 及 0.250：1.575 + 1.500/2 + 0.250/2 = **2.450 m**。
- 單向 Y 板的 **L = 2.450 m，B = 4.000 m**。舊 L 為 1.575 + 0.100 + 0.100 = 1.775 m。
- 淨面積仍為 **3.9375 m²**；200 mm 板自重為 **19.29375 kN**，顯示 19.29 kN。

尺寸取目前實體梁的位置，不使用已移位前的荷載參考線。支承缺口、重複支承和不規則板仍保留診斷，不會補造不存在的支承。

## 刻意保留的手動／自動差異

1. 自動 SB 可按 bay 重新分間；手動畫 SB 的間距及数量保留，只讓未固定的端點跟隨支承。
2. 明確輸入的梁闊、板跨度／板寬、板方向及柱中心仍優先於預設值。
3. 自動模型可重新生成構件；手動畫構件的記錄及荷載身份保留。來源標記仍存在，但不再單憑來源決定是否跟隨柱或識別 CB。
4. 位置固定不代表荷載路徑已成立；失去支承、碰撞或越界仍需處理。窄梁貼柱中心後若留下真實自由邊板條，不會因此假定外側有支承。
