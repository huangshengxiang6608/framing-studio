# E2.190 幾何與出圖上下層按鈕

「18 幾何與出圖」原本與柱圖例共用隱藏條件，令上下層按鈕也被隱藏。現在分開控制：平面模式顯示上下層按鈕，沿用原切層功能及首／末層停用規則；出圖頁柱圖例仍維持原樣。

不修改任何 Framing、構件、幾何檢查算法、傳荷、計算或出圖內容。Section A／B、Excel 模板、VBA、原 EXE 保留。使用者圈出的梁交接只作討論，未套用任何幾何修正或新增衝突判斷。

驗證：獨立 Chrome 三層合成專案檢查按鈕可見、逐層切換、首／末層停用、3D 隱藏及專案資料不變。所有其他 JavaScript 及報表／模板／原 EXE 逐檔核對不變。

網頁及源碼 E2.190；依原安排保留 E2.172 EXE。
