# E2.202 即時顯示梁預設尺寸

右鍵構件卡片切換 SB／MB／TB／CB 時，B 和 D 即時顯示按現有規則得出的尺寸，取代「留空恢復預設」和「套用後按參數更新」的空白欄位。D 仍只讀，按所選類型和當層／局部 Structural Zone 計算。預覽透過現有引擎在項目副本上執行，未按「應用」前不修改原項目。

顯示出的預設 B 不會被當作個別指定值儲存；往後改參數仍會跟隨。使用者重新輸入 B 才成為個別指定，切换類型時保留本次已輸入的 B。清空 B 並離開欄位會即時顯示預設數值，套用時恢復跟參數。

獨立 Chrome 測試通過：SB↔MB 來回切換的數值、預覽不改項目、套用後與預覽一致、預設 B 持續跟參數、個別 B 保留、清空恢復顯示，以及原本恢復預設／撤銷／重開和 MB→SB 分段編輯。已檢視數值預覽截圖。

本次只修改介面 app.js；其他計算模組、Section A／B、Excel 模板、VBA 及 EXE 逐檔不變。網頁／源碼 E2.202，套件按既有安排沿用 E2.172 EXE。
