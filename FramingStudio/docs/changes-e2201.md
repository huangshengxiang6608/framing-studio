# E2.201 手動／自動構件尺寸跟隨

修正舊自動 SB 讀取已保存闊度而不跟預設，以及改自動梁 B／D 後意外建立 EDIT 手動梁的問題。手動／自動的布置来源不再決定尺寸編輯後的行為。

梁：未個別指定的 SB／TB 闊度跟預設，MB／CB 闊度跟柱；SB 深度跟 Framing，MB／TB／CB 深度按 Structural Zone。個別 B／D 及既有局部深度上限保留。自動梁尺寸編輯保留原編號、自動布置來源及 Loading／Check／A 抄／B 抄的身分；凍結、保存重開保留個別尺寸，重新布置時沿用相同參考梁跨的指定值。不同梁跨不會依編號套入舊尺寸。靠邊梁加闊可向內貼邊，參考線保留。全清重新布置同時清除指定尺寸記錄。

柱：新加手動柱與自動柱均以 Framing 預設 B／D 起步。每項獨立為「跟參數」或「個別指定」，修改 B 不會固定未改動的 D。側欄、右鍵、逐列及批次修改一致；單項／逐列留空恢復預設，批次留空則保留各柱原值及模式。自動轉手動布置保留尺寸模式。舊手動柱／梁已有的明確尺寸不會被猜測為預設值；复制柱仍保留其當時尺寸和中心，需跟目標 Framing 預設時可留空重設。

保留合理的布置差異：手動梁位置由使用者指定，普通自動重排不會抹掉；自動梁按間距／方向和 primary bay 重排。兩者繼續共用既有支承連接、有效中間支承分跨、加柱／複製柱 SB→MB、MB→CB、上層柱 TB 判定及荷載計算。這次沒有新增任意 SB／MB／CB 的全雙向分類規則，也沒有改手動荷載輸入的含義。

驗證：新回歸涵蓋舊快照 SB 闊度／深度跟隨，自動 MB／SB 指定尺寸後的編號／來源／荷載和報表選取身分、凍結／重開／重新布置／恢復預設；手動與自動柱的獨立 B／D 模式、轉模式及舊尺寸保留。獨立 Chrome 測試側欄、右鍵、批次、逐列、留空、撤銷及重開，已檢視截圖。既有分跨、加柱／複製柱、CB、局部深度、slab 荷載、柱定位／放大缩小／多選／建議尺寸和梁批次編輯回歸通過。
