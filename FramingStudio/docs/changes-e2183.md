# E2.183 荷載與反力取整

| 項目 | 修改前 | 修改後 |
|---|---|---|
| 顯示兩位小數 | 部分位置只作四捨五入顯示 | 荷載／反力結果向上取兩位，直接顯示該值 |
| 板面荷載 | 隱藏小數可能進入下一步 | 面荷載取整，再乘係數並取整，再計反力 |
| Factored 板反力 | 從已取整 characteristic 反力重新乘係數 | 從取整的 Factored 面荷載計反力並取整 |
| 分項與合計 | 合計可能使用隱藏小數 | 相加畫面上的已取整分項 |
| SB→主梁 | 接收梁從 characteristic 分量再次建立設計荷載 | 另帶已取整 Factored 分量，接收梁直接採用，不重複乘係數 |
| 梁設計作用 | M/V 保留完整小數 | M/V 向上取兩位後送入既有 RC 驗算 |

## 2.45 m 板例

- 板自重：1.4×4.90＝6.86 kPa。
- 活荷載：1.6×7.50＝12.00 kPa。
- 每端 DL：6.86×2.45/2＝8.4035，向上取為 **8.41 kN/m**。
- 每端 LL：12.00×2.45/2＝**14.70 kN/m**。
- 合計使用這兩個結果：**8.41＋14.70＝23.11 kN/m**。

梁自重亦依序取整。例如 250×600 mm 梁，3.675 kN/m 先取 3.68，再乘 1.4 得 5.152，取為 5.16 kN/m。

取整發生於面荷載、加係數荷載、支承反力、接收構件的線／點荷載、梁 M/V 等結果階段；不改動跨度、位置等幾何數據。內部同時保留原 characteristic G/Q 路徑，供既有柱 Area／其他未修改功能使用。

## 保留範圍

按使用者確認，這次不把 RC 配筋公式逐項改成兩位小數；原 Excel 板配筋運算規則也保留。梁 RC 驗算接收新的取整 M/V。柱 tributary area 算法及幾何尺寸不变。Section A 抄與 Section B 抄的文字、公式展示、表格、圖、格式及分頁維持原樣，既有欄位的計算輸入值可隨本次更新。
