# E2.182 修改差異

| 項目 | 修改前 | 修改後 |
|---|---|---|
| SB 參數表 | Framing、預設深度、各層實際深度 | 只保留 Framing 與 SB 預設深度 |
| 超限輸入 | 自動改為樓層上限 | 明確提示所屬樓層及 Structural Zone 上限，拒絕套用，保留原設定 |
| 修正錯誤 | 失焦時焦點可能被錯誤提示拉回 | 提示保留在欄位旁，不搶焦點，可直接修正 |
| 荷載圖 | 加係數數值只靠上方說明辨識 | 每項數值直接加上 Factored，標題亦標示 Factored (ULS) |

共用 SB 預設須符合所屬各樓層及局部結構區上限。剛好等於上限可以套用；清空恢復 600 mm 時亦先檢查。拒絕後保留錯誤輸入供修改，但不儲存至專案，不產生有效修改或撤銷紀錄。舊專案已存的深度及既有模型限深規則未更改。

Factored 標示的 DL／LL 分量仍為 1.4 DL／1.6 LL，反力仍為其 ULS 合計。本次沒有新增或重複套用係數，手動輸入及明細仍為未加係數值。

驗證：獨立 Chrome 檢查超限拒絕後整份專案 JSON 不變、局部及一般樓層上限、等於上限、清空、錯誤後修正、欄位移除及 Factored 標示；既有板 UI、反力朝向及懸臂回歸通過，實際畫面已檢查。

計算模組、Section A/B 報表、Excel/VBA 及原 EXE 位元組保持一致。套件網頁／源碼為 E2.182，宿主沿用 E2.172，沒有重新編譯 EXE。
