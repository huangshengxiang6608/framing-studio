# E2.278 — Correct member caches, fresh CS selection and native PDF preflight

Baseline: E2.277 / `5f1e3a6bba461269e61e2242bd6ead55914e546f`. Official main, latest release and relevant PR heads were checked before work and publication; no remote changes were missing.

## Fixes

The native `CSAuto101` selection loop used worksheet-only recalculation before reading candidate-dependent formulas. Under manual calculation, a candidate could inherit the preceding candidate's effective depth, steel area or deflection result. A reproduced case selected T10@250 while its cached area still represented T12@100; a full recalculation exposed the failure. Fifteen of 24 CS cases disagreed before the fix. The three existing `s.Calculate` calls now use `Application.CalculateFull`. Equations, candidate limits and report renderers are unchanged. All 24 CS cases and 24 ordinary-slab cases now match App selection and success/failure results.

An additional end-to-end B-copy audit found that the bridge passed positional input-row offsets to native MB/SB cache Load/Save routines, while the original renderer uses `CacheRow66` member-ID lookup. Existing/previously selected cache entries made those positions diverge: SB56 could have a correct independent design sheet but blank cached steel in its B copy, and other SB rows could load another member's reinforcement. Both Load and Save now resolve and verify the native cache row by member ID. A regression fails on the pre-fix workbook and checks every MB/SB cached steel input against the selected member. Printed Excel error tokens block export. No native equations or report rendering routines change.

Section B export also adopts successful, fresh CS Check inputs and reinforcement, as it already does for other supported members. Failed automatic selection remains blocked. Section A's original slab/column schedule path remains unchanged.

The PaperSize failure was reproduced with Print Spooler stopped. After starting it, Windows could also hang while enumerating disconnected network printers although the local PDF driver's direct paper-capability query succeeded. Service recovery restored enumeration and native A4/PDF generation. Before opening a report, the bridge now checks Spooler, bounds printer enumeration in a disposable child process to 15 seconds, and exercises A4 on an unsaved blank workbook. An unavailable environment produces an explicit error before running report VBA. Cache hits do not need Excel or the printer preflight. The bridge does not start/stop services, remove printer connections, change the Windows default printer, or submit physical print jobs.

The existing Excel printer driver is preserved. Forcing another driver was rejected during validation because driver-dependent fit-to-page metrics can change. PDF export still uses the original native rendering and pagination routines. A later loss of the Windows printing service/network remains an environment error; this update does not claim to repair unavailable network printers permanently.

## Validation

- 257 extracted App formula definitions exactly match original workbook formulas: MB/SB/TB/CB 40 each, SLAB/CS 34 each, COL 29.
- 144 native Excel cases cover four beam types, ordinary slabs, cantilever slabs and columns, including different fire ratings/grades, zero/heavy/failing actions, torsion, manual unequal/eight-layer reinforcement and slender columns. All 5,296 formula results match.
- 48 native slab automatic-selection cases match reinforcement and pass/fail state. Successful automatic CS export passes 90 comparisons, produces its independent member sheet and native PDFs. In a disposable copy, 24 independent CS checks, manual edits, recalculation, isolation and save/reopen pass.
- Current saved model: Section A passes 2,607 comparisons; Section B passes 2,692; zero differences. Independent AC2/AC10 and named beam/slab sheets remain present. Cold A/B generation took 184.55 seconds; unchanged-model cache runs took 5.02 and 4.80 seconds and returned byte-identical verified workbooks. Both saved workbooks reopen in native Excel with CURRENT state. All 296 saved MB/SB steel inputs match the correct member identity, including eight non-positional mappings.
- Same-environment E2.277 comparison initially matched 25 A and 19 B pages pixel-for-pixel, but visual inspection exposed the inherited B-copy cache error above. After correcting member identity, B copy values intentionally change to the already checked member inputs/results; a pixel-equality claim for those corrected values would be wrong. Correct steel layers can change generated row positions under the original layout rules, so comparing row addresses against the previous wrong steel is not a valid formatting test. A control uses E2.277 source/template with only the two MB/SB cache accesses corrected to the native member-ID lookup, giving the same inputs to unchanged report rendering. Report values/styles, row/column dimensions, merged ranges, print settings, page breaks and rendered pages are compared against that control. A's values and rendered output remain unchanged. Generated PDFs are scanned for Excel cell errors as well as visually reviewed.
- The historical overnight output had a different printer-dependent effective zoom. Re-running the untouched E2.277 package in the current environment reproduces the current zoom, so comparison uses the unchanged original software in the same environment rather than altering original pagination rules to match another printer state.
- Template package audit: all 112 non-VBA parts are byte-identical, including formulas, formatting, drawings and print XML. Of 89 VBA modules, 88 are unchanged; only the three CS recalculation calls differ. The VBA compile cache is invalidated so Excel uses the corrected source.
- Printer preflight regression simulates success, failure and a blocked OS call. The blocked child is stopped after approximately 15 seconds without starting Excel or changing any printer/service settings.
- Existing acceptance, load-routing, tributary-column ownership, slab failure/preflight and report-adoption regressions pass. Automatic failures do not reuse stale reinforcement or bypass report gates.

## Scope and reproducibility

Legacy standalone beam VBA automatic detailing still has older policies than the user's explicitly requested App rules (equal occupied layers, compression/tension count alignment, minimum T10 links, maximum 250 mm spacing and alternative deflection acceptance). Generated reports adopt the checked App inputs and verify them against original Excel equations; this release does not silently revert those authorized policies or rewrite the legacy selection macros. The checks above establish parity for the stated test matrix, not every possible input combination.

Use `source/tests/report-cache-identity278.py VERIFIED_B_RUN` for the cache-ID/printed-error regression and `report-format278.py BASE_RUN NEW_RUN` for format preservation with identical member inputs; `report-equivalence254.py` also compares values and rendered pixels. Use `source/tests/rc-parity278.cjs OUTPUT_DIR`, then `rc-parity278.ps1 -DataDir OUTPUT_DIR` and `slab-auto278.ps1 -DataDir OUTPUT_DIR` on Windows with Excel. The native tests open the template read-only and never save it. `template-preservation278.py BASE_TEMPLATE` checks workbook-part preservation. `printer-preflight278.cs` compiles together with `ExcelBridge.cs` using `/main:PrinterPreflight278` and the bridge's normal references.

The model contains ordinary slabs but no CS, so CS coverage uses explicit fixtures. Existing Overall/Wind missing-input messages remain unresolved inputs, not RC calculation failures. Original B-copy L/d and Overall NOT OKAY text remains where the native L/d equation fails; App acceptance still uses RC plus span/depth or actual-deflection as explicitly requested. Independent calculation sheets remain editable snapshots; editing them does not update the app model or regenerate A/B copies. Packaging excludes private models, generated reports, diagnostic files and caches. Preview remains at localhost:8783 without forced reload or storage clearing.
