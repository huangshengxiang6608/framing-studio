# E2.192 禁柱區預設與 CB 出圖支承線

禁柱區只有「03 區域」預設顯示，其餘頁面預設隱藏。每頁可自行勾選，選擇在本次開啟期間獨立保留，不會因為其他頁面開啟而一起顯示，也不會刪除禁柱區資料或改變其計算效果。

「18 幾何與出圖」的 CB 符號改用不透明白底及實線輪廓，畫在普通梁和軸線之後，遮住穿過其截面的線條。柱、牆仍在 CB 之上。打印／SVG 使用同樣處理，兼容 E2.191 出圖位移。這是出圖處理，未新增支承、切斷梁或改動任何計算。

新符號必須由出圖介面明確開啟；Section A／B 及其他原生報表呼叫沿用原圖形。五個樓層案例已與 E2.191 比較，原生報表圖形及預設 SVG 完全一致；其他計算程式、報表檔、模板、VBA、EXE 逐檔不變。

驗證：獨立 Chrome 測試區域頁預設、其他頁預設、手動選擇互不影響、CB 繪圖選項及專案資料未改；檢視畫布。符號測試確認 CB 遮擋層次、白底實線、可選取範圍不變及隱藏 CB 開關。

網頁及源碼 E2.192；保留原 E2.172 EXE。
