# E2.197 出圖梁端跟柱

「幾何與出圖」移動柱時，原模型中落在該柱截面內、由該柱直接支承的梁端跟隨柱位移。另一端保留原出圖位置，所以沿梁方向移柱會拉長／縮短梁；兩端柱同量移動時梁整體平移。若單端橫向移動，出圖梁連接兩端顯示斜向外形，實際分析模型仍保持原樣。

以原柱支承關係識別，不會因移動後靠近其他柱而重新接駁；只有上層參考柱或原端點同時落在多支柱而關係不明時，不自行連動。梁和柱一起移動不會把該端位移加兩次。只移梁的原有操作保留；已有柱出圖位移會在新版直接套用連動，無須重做。

出圖所有可見梁面遮住背景軸線／Opening 線。梁交接時，落在另一條梁面內的邊線裁去，板方向線也會裁去穿梁部分。保留梁本身既有虛線／CB 實線樣式。柱、牆仍畫在梁上面。

畫布、梁選取範圍、端點／中點量距、打印／SVG 都採用連動後的出圖梁位置。單擊使用實際梁輪廓，避免斜梁外接框誤選；框選仍要求完整包住。圖紙出界檢查涵蓋伸長後梁面。保存重開、恢復 Functional Framing 及撤銷均保留。

這是出圖調整；原柱位、梁跨、支承、tributary area 及計算不改。Section A／B 沿用原報表圖形及格式，不套用本頁位移和遮線。

驗證：單柱移動伸長／縮短、兩端及梁柱共同移動不重複累加、斜向梁面、上層參考及歧義支承排除、線段裁切、SVG、保存重開及恢復。獨立 Chrome 確認延長梁段可選、恢復／撤銷重畫正確；多選、Shift 取消、完整框選、四方向位移及 Column above 回歸通過。視覺檢查平面圖，原模型／荷載列不變，五個樓層原生報表符號及預設 SVG 保留；報表／模板／VBA／EXE 逐檔一致。
