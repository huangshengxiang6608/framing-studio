# E2.187 受荷區尺寸與板反力作用區段

## 五項回饋

1. C1 的受荷區 X＝20.125–25.000、Y＝6.875–19.000 m，所以 X 長度 4.875 m、Y 長度 12.125 m；面積 59.109375 m²，依既有幾何顯示規則呈現 59.109 m²。沒有修改柱 tributary area 劃分。
2. 打開受荷區時，卡片同步顯示 X／Y 尺寸和座標範圍。矩形才標示面積＝X×Y；不規則、洞口或傳荷比例面積標示外包尺寸，避免誤解為外包矩形面積。
3. 舊「樓板」開關主要用於 3D 板體，平面底色沒有跟隨。現改名「樓板填色／3D」，平面填色也隨勾選改變。板方向與點選為獨立功能，不會取消計算中的樓板。
4. 舊版逐板把反力區段拉到全梁跨，遇到同一根梁跨越多塊板會重複覆蓋。現在每塊板只在自身左右支承中心線界定的區段加載；梁寬不會造成中間無荷載帶，也不會把半跨板荷載拉成全跨。跨滿一根 SB 的板仍全跨加載。自重仍按完整截面。
5. 小藍實心點是建築軸線交點，非額外構件或荷載。Summary Check 的選取模式隱藏該交點，繪圖模式保留定位點；梁端圓圈、梁中點及柱定位點保留。

## 驗證與保留

- 新合成案例：同一根 8 m 梁的左右板分別傳至 0–4／4–8 m，無重疊；反向梁、局部荷載分界和手動跨度換算通過。
- UI：真實 SVG 顯示分段荷載；平面樓板勾選前後圖像不同；選取模式無建築交點；受荷卡 X／Y 及座標完整可見。
- 既有 beam-independent179、slab-transfer177、rounding183、self-weight185、88 項柱中心測試、55 項荷載斷言及 12 項桁架案例通過。

- 柱面積法、完整公式取整及下游沿用顯示值規則保留。板梁荷載和反力會因修正區段而更新既有報表數值，報表格式／文字／公式呈現不變。
