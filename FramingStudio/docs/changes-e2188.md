# E2.188 受荷區前景尺寸線

按使用者示意圖，在受荷區上方顯示 X 尺寸線、左側顯示 Y 尺寸線，使用紅色尺寸及白色底／描邊。C1 範例為 X＝4.875 m、Y＝12.125 m，受荷面積仍顯示 59.109 m²。

原面積卡在 Drawing.plan 內繪製，但主介面隨後繪製板方向箭嘴，造成箭嘴蓋住卡片。現在介面延後受荷標註，於選取框、板方向、構件尺寸及其他畫布疊圖之後繪製尺寸線和面積卡。獨立平面預覽仍可直接繪製標註。

尺寸取自既有高亮受荷區外包邊界，與卡片共用數值，跟隨縮放／平移；部分超出視窗時標示「全長」。卡片選位避開尺寸標籤。非矩形或傳荷比例面積的既有說明保留。

驗證：獨立 Chrome 合成專案確認 foreground 在板方向及構件標註之後執行、兩條尺寸線存在；人工檢視實際畫布截圖，尺寸與面積卡清晰可見。既有樓板開關及分段荷載 UI 檢查通過。所有計算模組、報表／模板／VBA／原 EXE 及非本次修改的 bundle 內容逐檔核對不變。

網頁及源碼 E2.188；依原安排保留 E2.172 EXE。先保存專案，再用新套件開啟。
