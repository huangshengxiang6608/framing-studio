# E2.184 修改差異

| 項目 | 修改前 | 修改後 |
|---|---|---|
| 自動板方向 | 比較淨尺寸，邊板可能選不同軸向 | 按支承中心距選短跨；4×3 m 的板均選 Y 向 3 m |
| 梁頂 SDL／LL | 幾何梁頂範圍額外計算面荷載 | Section B 梁設計取消此項，採板／次梁傳荷及獨立梁自重 |
| RA／RB | 只列合計 | 合計下面列已取整的 Factored DL、LL |
| 圖表換行 | 按固定字數切斷數字 | 量度文字寬度，荷載數值與單位保留完整 |
| 批量梁參數 | B 與類型 | B 與 D；移除批量類型下拉，逐列類型原功能保留 |
| 指定 D | 主梁強制 Structural Zone | 明確指定值可小於或等於上限，未指定仍按原規則 |
| 共用 Framing | 梁深不能在此編輯 | 同步全部共用樓層；任何適用樓層／局部區域超限即整批不採用 |

梁深可逐列修改；逐列清空恢復預設，批量留空表示不修改。寬度修改保留已有深度。指定深度支援儲存、重開、撤銷及自動梁轉成手動梁。既有舊檔主梁 d 不會被誤當成新指定值。

## 傳荷來源

原「梁頂 SDL／LL」是「07 Loading」的面荷載乘剩餘梁頂計荷寬度。截圖例 1.6×7.50×1.50＝18.00 kN/m。按使用者最新要求，Section B 梁設計已移除此額外項目，樓板荷載經板反力→SB→主梁傳遞。柱 tributary area 和 Section A／Area 的幾何追蹤仍保留原算法；這次沒有把柱改為梁反力累加。
