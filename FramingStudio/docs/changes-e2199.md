# E2.199 梁類型自動判斷及尺寸跟隨

取消右鍵構件卡的「固定梁類型」。修改類型時不再自動加鎖；舊專案中手動梁及自動梁快照的 typeMode175 在讀取／驗證時清除。即使未經驗證直接生成模型，舊鎖定亦不阻止現有自動規則：MB 按支承判為 CB，加柱／複製柱令 SB 兩端得到柱牆直接支承時轉成 MB。原有固定位置選項保留；不新增支承關係或改寫分類判準。

原問題的另一原因是右鍵卡把唯讀的 D 數字存為手動深度。現在尺寸修改不再把唯讀顯示值寫回；未個別指定的 SB 繼續使用「00 參數」的 Framing SB 深度，受樓層／局部 Structural Zone 上限限制。改類型時清除舊類型深度；B 未被使用者另改時留空並套用新類型預設，避免把 MB 的尺寸帶進 SB。

已有手動尺寸不會被猜測為錯誤而全數清除。可右鍵該梁，按「恢復預設尺寸」清除其 B／D 個別指定；SB 跟共同 SB 預設闊及 Framing SB 深度，MB／CB 按柱闊規則、MB／CB／TB 深度按結構高度。可撤銷。之後修改參數及保存重開仍跟隨。手動畫出的 SB／TB 預設闊亦持續跟參數；明確手動改闊則保留該值。

驗證：獨立 Chrome 操作 MB→SB、參數改深度、只改 B 後再改深度、舊鎖定讀入、個別 D 重設／撤銷、預設 B 變更及保存重開；檢視構件卡截圖。加柱、單支／多支複製柱、短 CB 支承分類、荷載輸入及報表選取身份、樓層及局部梁深上限、批量 B／D 等既有回歸通過。報表／模板／VBA／EXE 逐檔保留，報表渲染未修改。自動分類與參數改變可按原計算更新既有欄位數值。

保留 E2.198 的 CB 出圖連動及支承完整邊線。網頁／源碼 E2.199；Windows 套件沿用 E2.172 EXE。
