# E2.195 取消選取及 Column above

出圖頁：左鍵仍累加選取；Shift＋左鍵只移除該項，不會加入未選構件。Shift 拖框會移除完整包住的構件；一般框選仍只加入完整包住的構件。Esc／清除選取及表格取消勾選保留。

Member Check：再點同一構件、Shift＋左鍵點目前構件、點空白或 Esc 會清除目前焦點、畫布焦點框及右側詳情。Check、A 抄、B 抄是保存的勾選，不會因取消焦點而被清除；要移除勾選仍可在右側取消。

出圖的 Column above 依上層所屬 Framing 的柱位移顯示；當層與上層各自使用自己的位移。先移動显示柱，再重新判斷上下層重疊片段，避免原本貫通的符號在柱移開後仍顯示原位。上層参考柱仍不能在本層選取移動，應切到上層操作。恢復某 Framing 亦同步恢復其在下層的參考圖形。打印／SVG 使用相同位置；圖紙出界檢查涵蓋移動後的上層柱。

此功能只調整幾何與出圖顯示，不改原柱位、tributary area、支承及荷載。Section A／B 沿用原符號、內容及格式，不套用出圖位移。

驗證：獨立 Chrome 測試 Shift 取消、再次點選、Esc／空白清除及 Check 勾選保留；多選／完整框選、四方向移動、保存重開、恢復／撤銷回歸通過。上下層獨立位移、重疊符號、保存重開及 SVG 測試通過，原模型和荷載列一致。報表／模板／VBA／EXE 逐檔保留。
