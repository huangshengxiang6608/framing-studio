# E2.196 複製柱後識別主梁

修正「複製至上層／下層」原先繞過 E2.194 補柱分類判斷的問題。單支及批量複製都會檢查目標層現有 SB：複製柱接到梁端點，另一端有有效柱或牆直接支承，而且類型沒有手動鎖定時，自動轉為 MB。

之前已複製的柱：使用新版後，在來源層再次選取該柱並按「複製至上層／下層」。目標層相同中心及尺寸的柱不會重複新增，但會重新檢查相關梁。完成提示會顯示轉為 MB 的數量。兩端柱都需複製的情況，在第二支柱加入後完成分類。

共用同一 Framing 的目標層同步。已有正確類型時再次複製不改資料；手動鎖定 SB、非端點接柱、另一端沒有柱／牆直接支承及純上層參考柱不會觸發轉換。既有 MB 分段規則保留。

原柱中心、尺寸、定位設定及源層資料保留。構件荷載識別、Check／A／B 勾選在轉換後繼續有效。批量複製任何一支有衝突仍整批取消，不留下部分柱或已轉換梁；可用原撤銷還原。

驗證：上／下層、單支／批量、手動／自動梁八組案例；已有柱修正、重複複製、兩端新增柱、類型鎖定、反力與荷載／報表引用、保存重開、衝突整批還原。原複製 UI 的中心／尺寸、九種定位、不同軸網、自動／手動模式、撤銷及重開回歸通過。Section A／B 報表程式、模板、VBA、EXE 逐檔保留。

網頁／源碼 E2.196；Windows 套件沿用 E2.172 EXE。
