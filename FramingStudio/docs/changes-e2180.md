# E2.180 修改差異

| 問題 | 修改前 | 修改後 |
|---|---|---|
| SB 深度 | 超過 Structural Zone 仍使用指定深度，只給提示 | 各層每根 SB 使用 min(指定／預設深度，所在結構區上限)，自動與手動畫梁一致 |
| 00 參數 | 只列共用輸入深度 | 新輸入受所屬樓層的最小一般結構區限制；列出各層實際深度及限深提示 |
| 梁反力 | 圖下方逐行顯示 DL／LL | A/B 支承處畫反力箭頭，標示 ULS 合力 kN；固定端另列彎矩 kNm |
| 板荷載 | characteristic 面荷載 | 列出係數 × 原值 = 設計荷載 kPa |
| 板反力 | characteristic DL／LL | 列出 1.4 DL／1.6 LL 分量及 ULS 合計 kN/m |

## 深度與傳荷

梁穿越不同局部結構區時採其中最小上限。各層獨立生成深度，MB／CB／TB 仍使用完整 Structural Zone。舊專案的超限輸入保留作為原指定值，但模型、自重及驗算都使用限深後的實際截面；參數頁列出實際深度。局部限制放寬後可恢復原指定值。清空共用輸入恢復預設 600 mm，实际深度仍受結構區限制。

以使用者板荷載為例：1.4 × 4.90 = 6.86 kPa、1.4 × 0 = 0、1.6 × 5.00 = 8.00 kPa。板反力依原有跨度計算後，畫面呈現加係數分量。內部 DL／LL 分量及手動荷載輸入仍採未加係數值，既有驗算只套用一次 1.4／1.6；不會將已加係數反力再次乘係數。

既有傳荷分量向上取兩位小數的規則保留，因此畫面反力從實際傳遞值加係數；例如 6.01／6.13 kN/m 顯示為 8.41／9.81，合計 18.22 kN/m。以未取整的理論反力直接乘係數，末位可能稍有不同。

柱仍採 tributary area。板反力全梁跨度及梁完整截面自重的 E2.179 行為保留。

## 反力圖與驗證

反力箭頭放在實際 A/B 支承位置，正反力向上、負值反向；懸臂只在固定端顯示反力及固定端彎矩。圖的朝向跟隨平面左→右／上→下，A/B 反向時標示亦對應。

參考：[Mississippi State University：梁自由體圖與支承反力](https://www.ae.msstate.edu/vlsm/non_con_force/non_concurrent_forces/examples/example2.htm)。

- 新獨立 Chrome 回歸：ULS 面荷載／反力、支承箭頭、倒轉 A/B、左右懸臂固定端、參數輸入上限及各層實際深度。
