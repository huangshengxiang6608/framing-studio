# E2.186 柱中心傳荷位置與 DL／LL

集中荷載以柱截面中心投影到接收梁的纵向位置，並從梁起點量距。柱的網格參考點仍用於定位、對齊及既有 tributary area 分界，不再充當集中荷載位置。

| 案例 | 原參考 X | 實際柱中心 X | 梁起點 X | 荷載位置 |
|---|---:|---:|---:|---:|
| C1 → TB23 | 25.00 | 24.25 | 20.25 | **4.00 m**（原 4.75） |
| C4 → TB_1 | 24.50 | 24.25 | 20.25 | **4.00 m**（原 4.25） |

同一中心座標用於自動轉換梁識別、支承核對、集中荷載、面積法沿 TB 分配及圖上標記。柱中心在梁寬內而不在梁軸線時，仍按縱向投影求位置；多個不明確接收梁及無效手動支承仍會被阻止。實際反力採用修正後的力臂，不只是修改標籤。

操作介面的柱荷載卡、累計圖、逐層表、牆面積表及桁架荷載／工況標籤統一使用 DL／LL。內部儲存鍵、計算變數和報表文字保留，舊專案可直接開啟。

- 88 項合成柱中心斷言：兩種參考偏移、水平／垂直、正向／反向梁、實際 solver 反力、柱面積荷載及 JSON 重新開啟。
- 獨立 Chrome UI 測試：兩個案例顯示 4.00 m，反力與 solver 相同；柱 DL／LL 名稱及面積荷載顯示正確，SVG 文字未超出邊界。
- 34 項自動轉換梁回歸；55 項既有荷載斷言及 12 項桁架整合案例通過。
- 完整自重公式取整、荷載／反力取整、slab 傳荷回歸通過。
- Section A 抄／Section B 抄及相關報表、Excel 模板、VBA、原 EXE 逐檔核對；除此輪列明的模組與版本號外，bundle 其餘內容保持一致。
