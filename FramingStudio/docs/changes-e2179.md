## 數例

支承中心 X=16.00、20.25 m，梁跨度為 4.25 m。兩塊板各傳入 DL=6.01、LL=6.13 kN/m；若 SB 為 250×600 mm，梁自重為 0.25×0.60×24.5=3.675，按既有规则向上取為 3.68 kN/m。

- 梁的全跨 DL = 6.01 + 6.01 + 3.68 = 15.70 kN/m。
- 梁的全跨 LL = 6.13 + 6.13 = 12.26 kN/m。
- 這些荷載的 DL 合力 = 66.725 kN；LL 合力 = 52.105 kN。
- 簡支兩端各 DL=33.3625 kN、LL=26.0525 kN。實際構件若另有附加荷載，仍另行計入。

同一板側的分段反力以整組區間映射到全梁跨；保留局部不同強度的順序與相對分段，不把每小段都各自鋪滿。柱 Area 幾何追蹤保留原有物理面積方法。構件独立自重與全跨板反力不再以整層物理混凝土去重作為梁驗算假設。
