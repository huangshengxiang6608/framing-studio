# E2.191 出圖梁多選位移

在「18 幾何與出圖」右側的「出圖梁位調整」清單勾選 MB／SB／TB／CB，或在平面圖單擊／框選累加。輸入移動距離 m，再按上／下／左／右。上＝−Y，下＝＋Y；清單顯示累計 ΔX／ΔY。Esc 清除選取；Delete 在本頁只清除選取，避免誤刪計算構件。

「恢復 Functional Framing」清除目前 Framing 全部出圖位移，而不只是已選梁。上方「撤銷」可撤銷移動或恢復。位移隨專案保存，重新開啟後保留；同一 Framing 且原始平面位置及梁闊一致的樓層共用。若原構件位置或梁闊改變，舊位移暫停套用並顯示提示。

只改本頁平面、構件標註、量距捕捉及打印／SVG 的梁位置。出圖移動不會自動拉長其他梁、重畫樓板、移动柱牆或解決支承關係。3D、原 Framing、所有計算、Section A／B 均用原位置。出圖頁的幾何提示仍以 Functional Framing 為準。移動後超出紙張時，打印／SVG 會要求調整比例，避免默默裁掉梁。

驗證：合成專案確認多選、四方向移動、負值拒絕、圖上移位後選取、框選、恢復／撤銷、存檔重新開啟及 Delete 防護。計算測試確認原模型和荷載列不變，出圖 SVG 只在指定選項時改變。與 E2.190 逐一比較五個樓層案例的原生報表圖形和預設 SVG，完全一致。所有計算模組、報表檔、模板、VBA 和 EXE 逐檔保留。

網頁及源碼 E2.191；保留原 E2.172 EXE。請先保存專案，再使用新套件。
